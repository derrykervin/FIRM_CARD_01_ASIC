# UID 与卡面编号
UID 使用 CHAR(10) ASCII 十进制；印刷号 CHAR(16)，两者独立数据库实体字段、各自 UNIQUE，保留前导零。都不是凭证。
候选：series(4)+FF1_K(UID, radix10 length10 tweak=固定系列及版本)(10)+check(2)。固定 key/tweak 内 FF1 为排列，跨系列/密钥仍由数据库唯一约束保证；服务器保留 series→密钥版本/参数注册表，禁止同系列静默轮换。
FF1 需选维护的实现，验证 NIST SP800-38G 及当前修订状态和官方 AES 已知答案、逆变换。当前无标准联网核验和可信 FF1 库，本次没有实现 FF1，也不宣称算法符合2026最终标准。十进制10位域=10^10，需按最终标准复核域下限和安全限制。禁止自行编写替代密码算法。
校验采用两位 MOD97：check=98-((first14×100) mod97)，严格按规范重算，完整号 mod97=1。参考实现已提供。仅发现输入错误，不防伪。
挂失/注销：卡记录状态立即阻断登录、撤销关联会话，历史不删；换卡分配新UID和新卡号，保留 supersedes 关联；账号ID不变，不复用旧编号。数学逆向返回UID后仍须查登记记录及状态。

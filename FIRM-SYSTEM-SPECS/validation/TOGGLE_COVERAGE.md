# Toggle覆盖报告
使用run_cvc_regression.py --toggle-coverage重新运行40个正向场景与1个fatal控制，41/41检查通过。每场使用optconfig只记录设计模块（不含测试台），没有把常量/未用位人为计为已翻转。40份原始toggle.rpt/toggle.tgldat、日志和命令保存于deliverables/cvc-toggle-regression；机器汇总cvc-toggle-summary.json。
计数含义是CVC记录的信号位0→1与1→0，不是寄存器面积/语句分支覆盖。不同测试场景不直接平均或相加，未实现跨层级路径联合合并；不能以最优场景百分比冒充全套覆盖。复位、force注入和常量稳定值会影响分母及翻转，需结合测试用途解释。数组/存储和别名计数以工具实际输出范围为限。

## 示例（常规联合CPB16/vector1/默认参数ID）
|模块|记录bits|0→1|1→0|
|---|---:|---:|---:|
|card|354|55.65%|55.65%|
|card_cpu|138|64.49%|64.49%|
|program_rom|24|100.00%|100.00%|
|spi_master|59|3.39%|3.39%|
|firm_reader_01|383|55.35%|55.09%|
SPI低翻转因为该登录场景不使用SPI；专用MMIO场景为57.63%/16.95%，仍有常量MISO等测试缺口。ROM的24bit输出翻转100%绝不意味着所有ROM地址/指令执行覆盖100%。实验RX2242个记录信号位约54.15%/53.57%，不等于已符合1x2面积。

## 覆盖工具控制实验
控制模块含3个信号位，1位人为0→1→0，2位始终0。toggle报告精确为每方向1hit/2miss/3bits，验证计数路径。
同一控制源包含明确未执行的分支和NEVER_EXECUTED_SENTINEL，日志没有执行该标志；但当前CVC语句报告在解释/编译配置下仍输出ALL STATEMENTS EXECUTED。原因未定（可能是实现/优化/配置口径），所以本轮拒绝将它当源码语句覆盖证据，没有报告100%语句覆盖或伪造豁免。原始探针证据保留在deliverables/cvc-coverage/control/；试验生成的模拟器二进制已删除，不随交付包分发。

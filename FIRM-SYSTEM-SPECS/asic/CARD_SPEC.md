# CARD 审计及目标
基线 feaa55682afc13b8ef6917de1e913a06ffae8ec0。8 位 CPU、8×8 位寄存器、256×16 ROM、无数据 RAM；LD 返回 0，ST 无操作。禁止向软件声称存在可用 RAM。若产品固件需要 LD/ST，先决定容量/寻址/上电语义并综合面积，不能直接恢复大 RAM 危及 1×2 tile。
UART/TIMER/SPI 来源 C0。Timer 字节小端，卡身份/认证大端；计时读数存在跨字节滚动，软件需一致性读取。UART 仅单字节 pending，需审计同周期读/接收及覆盖丢字节。
固定 CARD_ID 与公开 XOR/Rotate 仍存在。没有持久个性化或安全密钥存储，没有完整 eMMC host。
本地修改：wrapper MISO 从常零改为 ui[1]；新增 wrapper 读回测试，尚未 HDL 仿真。复位为外部低有效，释放同步与电源监控仍需系统验证。ena 尚未控制核心运行，需对照官方 harness 契约核验。
40MHz/347≈115273.8 baud；目标 1×2。本次改线后必须重新综合、STA、GDS、Precheck、GL；旧 GDS 不能作为新改线证据。

2026-10-31本地修复：UART_DATA旧字节读确认与新接收同沿时采用新接收优先，保留新pending；新增缓冲边界测试尚未仿真。单深度缓冲过载仍可覆盖旧数据，不能按本修复宣称可靠FIFO。
